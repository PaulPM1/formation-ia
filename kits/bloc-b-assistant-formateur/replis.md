# Replis préparés

## B1

Afficher `corriges/brief-chat-6-lignes.md`. Faire pointer les six sources et la section `À confirmer`, puis reprendre à B2.

## B2

Afficher un Artifact déjà généré selon `corriges/artifact-correction.md`. Le groupe exécute les quatre tests et formule la correction, même si aucune génération n’a lieu en direct.

## B3

Copier `corriges/brief-cowork.md` vers `sortie/brief-du-jour.md`, puis exécuter `node verify-cowork.mjs`. Pour un cas négatif, retirer une source ou remplacer `À confirmer` par une décision.

## B4

Montrer `corriges/claude-code.patch`, appliquer la modification préparée sur une copie formateur, exécuter `node --test` et relire le diff inline dans VS Code.

## B4-bis

Si le poste ne passe pas `node --test` dans les dix minutes, basculer en observation sur un poste prêt. Toute installation complète se termine hors chrono.
