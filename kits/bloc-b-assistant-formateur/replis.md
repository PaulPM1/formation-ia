# Replis préparés

## B1

Afficher `corriges/brief-chat.md`. Faire pointer les six sources et la section `À confirmer`, puis reprendre à B2.

## B2

Afficher un Artifact ou un Canvas déjà généré selon `corriges/objet-correction.md`. Le groupe exécute les cinq tests : six cartes visibles, déplacement vers `Plus tard`, archivage, total toujours égal à six, puis remise à zéro avec six cartes dans `Aujourd’hui`. Il formule ensuite la correction, même si aucune génération n’a lieu en direct.

## B3

Copier `corriges/brief-agent.md` vers `mission-agent/sortie/brief-du-jour.md`, puis exécuter `node mission-agent/verify-brief.mjs`. Pour un cas négatif, retirer une source ou remplacer `À confirmer` par une décision.

## B4

Montrer `corriges/agent-code.patch`, appliquer la modification préparée sur une copie formateur de `mini-application/`, exécuter `node --test` et relire les fichiers modifiés ainsi que le diff dans Claude Code ou Codex.

## B4-bis

Si le poste ne passe pas `node --test` dans `mini-application/` au bout de dix minutes, basculer en observation sur un poste prêt. Toute installation complète se termine hors chrono.
