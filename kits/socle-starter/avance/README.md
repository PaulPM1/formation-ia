# Nom du projet

> Une phrase : ce que fait le projet, et pour qui.

## Ce que ça fait

> Trois à cinq puces concrètes, du point de vue de l'usage.

## Ce que ça ne fait pas

> Les limites assumées, en particulier tout ce qui sort ou publie une
> information.

## Comment l'utiliser

> Les étapes pour obtenir le résultat principal, depuis un dossier fraîchement
> cloné. Commande, prérequis, format attendu en entrée.

## Organisation des fichiers

> Un dossier par ligne. Voir `DOSSIERS.md`.

## État d'avancement

- [ ] Socle : dossier versionné, `CLAUDE.md` rédigé, premier commit poussé.
- [ ] Matière : arborescence décidée, règles de routage écrites, contenu chargé.
- [ ] Savoir-faire : le résultat principal se produit en une commande.
- [ ] Visage : une page consultable, en local puis en ligne.
- [ ] Sécurité : audit passé, aucun secret dans le dépôt.

## Sécurité

> Où vivent les secrets, ce que le dépôt ne contient pas, quand vous relancez
> l'audit de `prompts/securite.md`.

> Votre prénom et le lien que vous choisissez d'exposer publiquement.
