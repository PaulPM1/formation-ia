# Kit de départ

Le point de départ commun à tous les projets de l'atelier. Il ne contient aucun
code et rien qui soit propre à un projet précis : juste ce dont tout projet a
besoin pour démarrer proprement et sans risque.

## Ce qu'il contient

- `.gitignore` : la liste de ce qui ne doit jamais partir en ligne (vos clés,
  vos secrets). Déjà rempli, ne le videz pas.
- `CLAUDE.md` : le fichier d'identité de votre projet. Vide au départ : c'est
  l'interview qui le remplit (voir plus bas).
- `prompts/interview.md` : le prompt qui fait écrire votre `CLAUDE.md` par
  Claude, à partir de vos réponses.
- `prompts/securite.md` : les deux prompts de sécurité, à garder sous la main
  pour tout le week-end.

Pas de dossiers de contenu imposés : chaque projet crée sa propre structure au
moment où il en a besoin, à l'étape « La matière ».

## Comment démarrer

1. Créez votre dépôt depuis ce modèle avec le bouton **Use this template** de
   GitHub, puis faites-le cloner sur votre machine par Claude.
2. Ouvrez le dossier dans VS Code.
3. Ouvrez `prompts/interview.md`, copiez le prompt dans Claude, répondez aux
   questions : Claude écrit votre `CLAUDE.md`. Vous relisez et corrigez.
4. Faites un premier commit et poussez-le sur GitHub.

À partir de là, suivez le cahier des charges de votre projet sur le site de
l'atelier.
