## L'essentiel

Dans l'onglet **Code**, Claude travaille dans un dossier de votre ordinateur. Vous demandez, vous regardez, vous corrigez.

<ClaudeCodeLoop />

## À essayer

**1. Ouvrez un dossier vide dans l'onglet Code.**

<OpenFolder />

**2. Demandez une première page.**

<PromptCopy>Crée une page qui présente mon plat préféré, avec un titre, une photo et la recette. Montre-la-moi dans l'aperçu.</PromptCopy>

**3. Demandez un changement qui se voit.**

<PromptCopy>Mets un fond plus chaleureux et le titre plus grand.</PromptCopy>

**4. Faites-lui écrire sa mémoire.**

<PromptCopy>Note dans un fichier CLAUDE.md ce qu'est ce projet et comment je veux que tu me parles.</PromptCopy>

### CLAUDE.md est sa mémoire

<ClaudeMemory />

<details class="hint">
  <summary>Pour aller plus loin</summary>
  <p><strong>Quand la conversation s'allonge.</strong> Claude perd le fil des longues conversations. Ouvrez-en une nouvelle dans le même dossier : <code>CLAUDE.md</code> suffit pour reprendre.</p>
  <p>Documentation officielle : <a href="https://code.claude.com/docs/en/desktop">Claude Code dans l'application de bureau</a>.</p>
</details>

<details class="hint">
  <summary>Notes formateur</summary>
  <p><strong>Démonstration en direct, dix minutes.</strong> Partez d'un dossier vide, projeté. Faites la première demande à voix haute avant de l'écrire, laissez le groupe lire la demande de permission avec vous, puis montrez l'aperçu. Demandez à la salle la correction : c'est elle qui dicte.</p>
  <p><strong>À faire voir.</strong> Le dossier avant et après, dans l'explorateur de fichiers : les fichiers sont bien là, sur l'ordinateur. Puis une nouvelle conversation qui relit <code>CLAUDE.md</code>.</p>
  <p><strong>Pièges fréquents.</strong> Une demande qui contient cinq idées à la fois : faites-la découper. Une personne qui lit le code au lieu de regarder l'aperçu : ramenez-la à l'aperçu. Une permission acceptée sans être lue : relisez-la ensemble une fois.</p>
</details>
