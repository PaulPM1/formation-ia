## L'essentiel

Un **skill** est un savoir-faire rangé dans un dossier. Claude le charge quand votre demande en a besoin.

<SkillLoads />

## À essayer

**1. Demandez à Claude ce qu'il sait déjà faire.**

<PromptCopy>Quels skills as-tu sous la main, et à quoi sert chacun ?</PromptCopy>

**2. Ajoutez-en un.** Par exemple [setup-projet](/kits/setup-projet.zip), celui qui cadre votre projet.

### La troisième fois, faites-en un skill

Vous venez d'expliquer la même méthode pour la troisième fois ? Demandez à Claude de l'écrire : vous n'ouvrez jamais le fichier vous-même.

<details class="hint">
  <summary>Pour aller plus loin</summary>
  <p><strong>Où vivent les skills.</strong> Un skill ajouté depuis cette page vous suit dans toutes vos conversations. Un skill rangé dans le dossier d'un projet ne sert que dans ce projet.</p>
  <p><strong>Plugins.</strong> Un plugin est un paquet tout fait qui regroupe plusieurs skills et connecteurs. La même page en propose, dans son onglet <strong>Plugins</strong>.</p>
  <p><strong>Prudence.</strong> Un skill est une suite de consignes que Claude suivra : n'ajoutez que ceux dont vous connaissez l'auteur.</p>
  <p>Documentation officielle : <a href="https://support.claude.com/en/articles/12512180-using-skills-in-claude">utiliser les skills dans Claude</a> et <a href="https://code.claude.com/docs/en/skills">les skills dans Claude Code</a>.</p>
</details>

<details class="hint">
  <summary>Notes formateur</summary>
  <p><strong>Démonstration en direct, cinq minutes.</strong> Dans un dossier vide de l'onglet Code, écrivez « lance setup-projet » et laissez le groupe voir la première question arriver : c'est le skill qui parle. Arrêtez-vous là, le cadrage complet vient avec la brique E3.</p>
  <p><strong>À faire voir.</strong> L'ajout depuis Plugins, Skills, Add, avec le fichier <code>setup-projet.zip</code>. Puis le fichier <code>SKILL.md</code> ouvert une fois, pour montrer que ce n'est que du texte : une description, puis une méthode.</p>
  <p><strong>Pièges fréquents.</strong> Un skill absent de la liste : vérifiez dans les réglages que la création de fichiers et l'exécution de code sont activées. Un skill qui ne se déclenche pas : nommez-le dans la demande. Une personne qui veut écrire le fichier à la main : ramenez-la à la phrase du geste 3.</p>
</details>
