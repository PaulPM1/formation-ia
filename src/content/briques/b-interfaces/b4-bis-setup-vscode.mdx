## Cap

**Objectif :** disposer d'un espace de travail commun pour voir les fichiers, ouvrir un terminal et suivre les modifications d'un projet.

- Durée indicative : 15 à 30 minutes selon les droits d'installation.
- Prérequis : accès au Web et droit d'installer VS Code, ou version déjà présente.
- Résultat attendu : le dossier `atelier-ia` est ouvert, `bonjour.txt` existe et le terminal intégré répond.

VS Code est l'éditeur utilisé pendant la formation. Les étapes de base se valident sans extension ; l'extension Claude Code s'ajoute ensuite, et c'est elle qui rend le travail confortable.

## Concept durable

Un **éditeur de code** travaille sur des fichiers et des dossiers. Dans VS Code :

- l'**Explorateur** montre l'arborescence réelle ;
- l'**éditeur** affiche le contenu du fichier actif ;
- le **terminal intégré** exécute les mêmes outils qu'un terminal séparé ;
- le **workspace** est le dossier ouvert et peut contenir des réglages propres au projet.

Ouvrir un dossier donne du contexte aux outils. N'accordez la confiance qu'aux dossiers dont vous connaissez l'origine : un projet téléchargé peut contenir des tâches ou réglages exécutables.

Une **extension** ajoute une capacité à l'éditeur : un langage, un formateur, un outil. Elles s'installent depuis la vue Extensions et se désactivent aussi facilement.

L'extension qui change le quotidien ici est **Claude Code**. Elle apporte dans l'éditeur ce que le terminal montre mal : les modifications proposées s'affichent en comparaison côte à côte, avec accepter ou refuser pour chacune ; le plan d'action se relit et s'amende avant exécution ; les fichiers se désignent par mention plutôt que par chemin complet ; et l'historique des conversations reste accessible. C'est la manière recommandée d'utiliser Claude Code dans VS Code. Le terminal garde son intérêt : certaines commandes n'existent que là, et les deux partagent la même conversation.

## Pratique avec Claude

1. Téléchargez VS Code depuis la page officielle si nécessaire.
2. Installez la version Stable adaptée à votre système.
3. Créez un dossier `atelier-ia` dans `Documents`.
4. Dans VS Code, choisissez **Fichier → Ouvrir le dossier**, puis sélectionnez `atelier-ia`.
5. Créez `bonjour.txt` avec :

```text
Mon atelier IA est prêt.
```

6. Ouvrez **Terminal → Nouveau terminal** et vérifiez que son chemin se termine par `atelier-ia`.
7. Exécutez `code --version` si la commande `code` est configurée. Sinon, le test du terminal reste valide et la configuration est traitée dans le dépannage.
8. Ouvrez la vue Extensions, cherchez « Claude Code » et installez l'extension officielle publiée par Anthropic.
9. Ouvrez le panneau Claude depuis l'éditeur, puis connectez-vous avec votre compte Claude. Aucune clé d'API n'est demandée.
10. Demandez une modification simple de `bonjour.txt` et observez la comparaison proposée avant d'accepter ou de refuser.

## Mission commune

Sans aide du formateur, fermez puis rouvrez VS Code, ouvrez `atelier-ia`, modifiez `bonjour.txt` et utilisez le terminal pour afficher le dossier courant.

- macOS avec zsh : `pwd`
- Windows PowerShell : `Get-Location`
- Git Bash : `pwd`

**Critère de réussite :** le fichier est visible dans l'Explorateur et le terminal indique le même dossier.

## Livrable

Le dossier `atelier-ia` contenant `bonjour.txt`, plus la sortie de la commande de localisation. Ce dossier servira de zone de travail non sensible pour les exercices suivants.

## Notes formateur

- Séparer les participants par système pendant les cinq minutes d'installation.
- Demander le test final avant d'ajouter des extensions ou de personnaliser l'interface.
- Expliquer le triptyque « dossier, fichier, terminal » au vidéoprojecteur.
- Ne pas utiliser de projet téléchargé pour le premier test de Workspace Trust.

Transition : un environnement visible et un terminal fonctionnel permettent d'aborder les extensions réutilisables, les connexions MCP et les automatisations.

## Défis avancés

- Configurer la commande `code` puis ouvrir le dossier depuis le terminal avec `code .`.
- Ouvrir la palette de commandes et retrouver « Terminal: Create New Terminal ».
- Comparer réglages utilisateur et réglages du workspace sans modifier les fichiers de configuration.

## Variantes

- **Installation interdite :** utiliser la version déjà approuvée par l'organisation ou suivre la démonstration ; ne pas contourner les politiques.
- **Autre éditeur déjà maîtrisé :** valider malgré tout l'ouverture du dossier et du terminal dans VS Code pour partager les mêmes repères pendant la formation.
- **Clavier non français :** utiliser les menus plutôt que les raccourcis.

## Dépannage

- **Le dossier n'apparaît pas :** utiliser « Ouvrir le dossier », pas seulement « Ouvrir un fichier ».
- **Le terminal s'ouvre ailleurs :** fermer le terminal, rouvrir le bon dossier puis créer un nouveau terminal.
- **Workspace Trust apparaît :** n'accorder la confiance qu'au dossier `atelier-ia` créé par vous-même.
- **`code` est introuvable :** suivre les étapes propres au système ci-dessous ; cela ne bloque pas l'usage de VS Code par les menus.
- **L'extension reste invisible après installation :** recharger la fenêtre depuis la palette de commandes, puis ouvrir un fichier ; certains points d'entrée n'apparaissent qu'avec un fichier ouvert.
- **La commande `claude` reste introuvable dans le terminal intégré :** l'extension embarque sa propre copie pour son panneau, mais la commande du terminal s'installe séparément. Les deux peuvent coexister et partagent l'historique des conversations.

## Ouverture

Vous disposez maintenant d'un dossier de travail explicite, d'un éditeur et d'un terminal. La famille C montre comment ajouter à Claude des méthodes, des connexions et des déclencheurs.

## Diagnostic initial

Avant d'installer :

1. recherchez « Visual Studio Code » dans les applications ;
2. ouvrez-le et consultez **Aide → À propos** sur Windows ou **Code → À propos** sur macOS ;
3. tentez d'ouvrir un dossier et un terminal ;
4. n'effectuez une installation que si un de ces tests essentiels échoue.

## Test final

Le setup est validé lorsque :

- VS Code ouvre `atelier-ia` comme dossier ;
- l'Explorateur affiche `bonjour.txt` ;
- le fichier contient « Mon atelier IA est prêt. » ;
- le terminal intégré pointe vers `atelier-ia` ;
- vous savez fermer puis rouvrir ce dossier.

## Dépannage Mac

1. Ouvrez le fichier `.dmg` officiel et glissez **Visual Studio Code.app** dans `Applications`.
2. Lancez VS Code depuis `Applications` ou Spotlight.
3. Pour ajouter `code` au `PATH`, ouvrez la palette avec `Cmd+Shift+P`, cherchez **Shell Command: Install 'code' command in PATH**, exécutez-la puis ouvrez un nouveau terminal.
4. Si la commande reste absente, poursuivez avec les menus et redémarrez le terminal après la session.

## Dépannage Windows

1. Utilisez de préférence le **User Setup** officiel si vous n'avez pas les droits administrateur.
2. Fermez puis rouvrez les terminaux après l'installation afin qu'ils récupèrent le `PATH` mis à jour.
3. Si `code` n'est pas reconnu, vérifiez l'option d'ajout au `PATH` ou réinstallez depuis la source officielle.
4. En environnement géré, demandez l'installation au support interne au lieu d'utiliser une archive non approuvée.
