## Cap

**Objectif :** démarrer une mission individuelle continue sans consommer le temps de pratique en installation.

- Durée exacte : 5 minutes.
- Socle B0 à B3 : 55 minutes, plus 5 minutes de marge de transitions.
- Parcours facultatif B4 : 20 minutes.
- Rattrapage B4-bis : 10 minutes, isolé du parcours principal.

Chaque participant dispose avant le chrono d’un compte compatible, de la création d’Artifacts activée, de Claude Desktop connecté pour Cowork et du kit décompressé. Une installation complète se termine hors chrono.

## Concept durable

Les quatre outils travaillent sur la même matière mais ne prouvent pas la même chose :

1. Chat produit un brief sourcé.
2. Artifact rend ce brief manipulable et testable.
3. Cowork crée un fichier dans un périmètre borné.
4. Claude Code modifie la mini-page, exécute un test et présente un diff.

Le cas contient six notes entièrement fictives réparties dans trois fichiers. Deux notes donnent volontairement des dates contradictoires, le 18 et le 19 septembre.

## Pratique avec Claude

Ouvrez `kits/bloc-b-assistant/README.md`, puis envoyez dans Chat :

```text
Réponds uniquement par « Atelier prêt » puis donne la date du jour.
```

Vérifiez ensuite que la création d’Artifacts est activée et que Claude Desktop est ouvert, connecté et affiche Cowork.

## Mission commune

Effectuez les quatre contrôles dans l’ordre :

1. Chat répond « Atelier prêt » avec la date du jour.
2. La création d’Artifacts est disponible.
3. Cowork est visible dans Claude Desktop connecté.
4. `kits/bloc-b-assistant/README.md` et les trois fichiers de `inbox/` s’ouvrent.

Si un seul maillon manque sur un poste presque prêt, ouvrez B4-bis depuis le sommaire. Ne lancez pas une installation longue.

## Livrable

Une checklist de quatre contrôles. Le résultat attendu est `4/4` ou un repli explicitement choisi avant le départ.

## Notes formateur

- De 00:00 à 02:00 : afficher `kits/bloc-b-assistant/README.md` et la chaîne des quatre preuves.
- De 02:00 à 05:00 : faire exécuter les quatre contrôles.
- Couper à 05:00, même si un poste n’est pas totalement installé.
- Repli : fournir le dossier déjà décompressé, utiliser Chat dans le navigateur et orienter un poste presque prêt vers B4-bis.
- Toute donnée reste fictive ; aucun mot de passe, jeton ou document professionnel n’est partagé.

## Défis avancés

- Ouvrir le kit depuis le terminal sans modifier de fichier.
- Vérifier que `node --test` passe dans `kits/bloc-b-assistant/code/` si B4 est prévu.

## Variantes

- **Socle uniquement :** B0 à B3, puis C1.
- **Parcours complet :** B0 à B3, 5 minutes de marge, puis B4.
- **Poste presque prêt :** B4-bis depuis le sommaire, sans entrer dans la séquence principale.

## Dépannage

- **Artifact absent :** vérifier le réglage de création de code et utiliser l’Artifact formateur préparé.
- **Cowork absent :** vérifier le compte et Claude Desktop ; basculer sur le scénario observateur si nécessaire.
- **Kit introuvable :** redécompresser `bloc-b-assistant.zip` dans un dossier local connu.
- **Installation requise :** noter le maillon manquant et poursuivre avec le repli préparé.

## Ouverture

Les six notes sont prêtes. B1 commence par une demande volontairement vague afin de rendre visibles les décisions que Chat serait obligé d’inventer.

## Diagnostic initial

Demandez uniquement : Chat répond-il, Artifact est-il activé, Cowork est-il connecté, le kit est-il lisible ? Toute autre configuration sort du préflight.

## Test final

Le préflight passe avec quatre preuves observables : réponse Chat, accès Artifact, accès Cowork et dossier local ouvert. Une apparence d’installation ne suffit pas.

## Dépannage Mac

- Vérifier que Claude Desktop est ouvert depuis `Applications` et connecté.
- Décompresser le ZIP dans `Documents` si le dossier est encore lu depuis l’archive.
- Pour B4, ouvrir directement `kits/bloc-b-assistant/code/` dans VS Code.

## Dépannage Windows

- Vérifier que Claude Desktop est ouvert et connecté, pas seulement présent dans le menu Démarrer.
- Extraire tout le ZIP avant d’ouvrir les fichiers.
- Pour B4, ouvrir `kits\bloc-b-assistant\code` comme dossier dans VS Code.
