## L'essentiel

Vous collez une phrase. Claude installe ce qu'il faut et relie votre compte GitHub.

<details class="hint">
  <summary>Pour aller plus loin</summary>
  <p><strong>Si quelque chose bloque, trois réflexes.</strong> Fermez complètement l'application Claude et rouvrez-la : elle ne voit les nouveaux outils qu'après. Collez le message d'erreur à Claude, avec « répare ça et explique-moi en deux phrases ». Au deuxième échec, appelez un formateur.</p>
  <p><strong>Chez vous, plus tard.</strong> Votre ordinateur reste prêt. S'il manque un outil un jour, la même phrase répare : elle n'installe que ce qui manque.</p>
  <p>Documentation officielle : <a href="https://code.claude.com/docs/en/desktop">Claude Code dans l'application de bureau</a>, <a href="https://docs.github.com/fr/get-started/start-your-journey/creating-an-account-on-github">créer un compte GitHub</a>.</p>
</details>

<details class="hint">
  <summary>Notes formateur</summary>
  <p><strong>Premier geste du samedi, avant toute théorie.</strong> Projetez la phrase, collez-la avec le groupe, puis laissez les installations tourner pendant le premier bloc. Passez voir les tableaux à la première pause.</p>
  <p><strong>À faire voir.</strong> Une demande de permission lue à voix haute avant d'accepter, puis la page GitHub où l'on colle le code. Le mot de passe demandé est celui de l'ordinateur, jamais celui de Claude ni de GitHub.</p>
  <p><strong>Pièges fréquents.</strong> Un outil « introuvable » juste après son installation : quitter l'application et la rouvrir. Un ordinateur de travail qui refuse toute installation : ne pas insister, passer en session cloud ou en binôme. Le guide manuel, la table des pannes et le plan B sont dans <code>docs/atelier/installation-depannage.md</code>.</p>
  <p><strong>À prévoir.</strong> Une clé USB avec les installateurs, un partage de connexion de secours, un ou deux ordinateurs déjà prêts.</p>
</details>
